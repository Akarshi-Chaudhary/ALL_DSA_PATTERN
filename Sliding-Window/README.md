# Sliding Window

## Pattern Recognition

Use Sliding Window when the problem involves:
- Subarray
- Substring
- Contiguous elements
- Fixed window size
- Longest/shortest subarray or substring

## Types

### 1. Fixed Size Window
Window size = k

### 2. Variable Size Window
Expand with right pointer and shrink with left pointer.

## Problems

- Maximum Sum Subarray of Size K
- First Negative Number in Every Window
- Longest Substring Without Repeating Characters
- Minimum Size Subarray Sum
